# Social Media Campaign Performance Tracker

## 📌 Objective
To analyze the performance of different marketing channels and identify which channels contribute the most to product sales.

## 🛠 Tools Used
- Power BI

## 📂 Dataset
The dataset contains marketing spend and performance data for the following channels:
- Google Ads
- TV
- Social Media
- Billboards
- Influencer Marketing
- Affiliate Marketing

## 📊 Dashboard Overview
An interactive Power BI dashboard was created to visualize:
- Total sales contribution by each marketing channel
- Comparative performance using bar charts
- Overall sales trends and insights

## 🔍 Key Insights
- Google Ads and TV are the top-performing marketing channels.
- Billboards and Social Media show moderate performance.
- Influencer and Affiliate Marketing contribute comparatively less to total sales.

## ✅ Outcome
The dashboard helps stakeholders make data-driven decisions by clearly identifying high-performing and low-performing marketing channels.
